# أسرة الرياضيات – تطبيق أندرويد (APK)

تطبيق «أسرة الرياضيات» للرياضيات المتقدمة – الصف الثاني عشر (الفصل الأول)، يعمل على الهاتف والتابلت دون إنترنت.

أسرة الرياضيات

## تنزيل التطبيق
افتح صفحة **Releases** في هذا المستودع، ونزّل ملف `family-math-12.apk` من أحدث إصدار، ثم افتحه على الجهاز واسمح بالتثبيت من هذا المصدر عند السؤال.

## كيف يُبنى
عند كل رفع إلى الفرع `main` يبني GitHub Actions ملف APK موقّعاً ويضعه في صفحة Releases تلقائياً (سير العمل: `.github/workflows/build-apk.yml`). ويمكن تشغيله يدوياً من تبويب **Actions** ← «بناء APK أسرة الرياضيات» ← **Run workflow**.

## تحديث المحتوى
1. ابنِ حزمة PWA الجديدة لأسرة الرياضيات (`build_family_app.py`).
2. شغّل: `python3 tools/prepare_www.py <مسار-تطبيق-أسرة-الرياضيات-للتثبيت-على-أندرويد.zip>`
3. ارفع التغييرات إلى `main`، فيُبنى إصدار جديد يُثبَّت فوق القديم دون حذف بيانات المعلم.

## ما يضيفه التطبيق على نسخة الويب
- حفظ ملفات SCORM وغيرها في: التنزيلات ← أسرة الرياضيات.
- الطباعة أو الحفظ PDF من أي صفحة (مثل مولّد الاختبارات).

## التوقيع
يُوقَّع التطبيق بمفتاح ثابت محفوظ في أسرار المستودع (`KEYSTORE_B64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) حتى تُثبَّت التحديثات فوق الإصدار السابق. لا تحذف هذه الأسرار.
